# All Sorted Content Studio

Use `DIRECTOR.md` as the complete platform-neutral operating protocol. `skill/SKILL.md` is the entry point and `agents/` contains the worker instructions. Set `CONTENT_STUDIO_DIR` to this folder or its installed copy before running commands.

The five tools are HookLab, Ad Images, Carousel Builder, HeyGen Ad Videos, and Video Editor. The director coordinates the workers and returns a reviewed handoff. Never upload ads, spend money, or touch an ad account.
