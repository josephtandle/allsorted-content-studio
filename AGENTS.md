# All Sorted Content Studio

Use `DIRECTOR.md` as the complete platform-neutral operating protocol. `skill/SKILL.md` is the entry point and `agents/` contains the worker instructions. The studio root is the folder that contains this file; use that folder when a command needs the studio root.

The six tools are HookLab, Ad Images, Carousel Builder, HeyGen Ad Videos, Video Editor, and Launch Video. The director coordinates the workers and returns a reviewed handoff. Never upload ads, spend money, or touch an ad account.
