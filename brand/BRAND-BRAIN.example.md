# Brand Brain

This fictional example is a completed Brand Brain. The Markdown is the source of truth, and `node scripts/studio.mjs brand-json` generates `brand/brand.json`.

## Business and offer
- Brand name: Sunrise Yoga Studio
- Offer: Beginner yoga classes, one 60-minute small-group introduction class
- Price or terms, if approved: $25 per class, booking required, fictional example offer
- Destination: https://example.com/sunrise-yoga

## Audience
- Specific audience: Adults curious about yoga who want a calm first class
- Current situation: Interested in trying yoga, but unsure what a first class involves
- Problem in their words: Starting something new can feel intimidating
- Desired supported outcome: Learn a few gentle movements in a welcoming class

## Evidence and claims
- Approved facts and proof: One 60-minute beginner class, Small-group format, Fictional example offer
- Testimonials with permission: none
- Claims to avoid: guaranteed health outcomes, medical treatment claims, weight-loss promises

## Voice and visuals
- Voice: Warm, calm, practical, welcoming, and specific
- Background color: #FFF8EC
- Ink color: #25443B
- Accent color: #E98256
- Display font: Georgia
- Body font: Arial
- Image direction: Natural morning light, simple studio details, no body transformation imagery

## CTA
- Primary action: View class times and book a beginner class
- CTA wording: See the beginner class schedule
