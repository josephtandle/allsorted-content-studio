# Rendered examples

These sample files use fictional business copy for Sunrise Yoga Studio. The proof slide is an explicit placeholder, not a testimonial. Replace it with a real, permissioned quote or remove that content before using a creative in an ad.

The six square PNGs demonstrate an Instagram carousel. `sunrise-yoga_01_hook-card_feed.png` and `sunrise-yoga_01_hook-card_story.png` demonstrate the 4:5 and 9:16 dimensions. The HTML templates remain editable in `../templates/`.
