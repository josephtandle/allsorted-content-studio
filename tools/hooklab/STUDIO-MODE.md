# HookLab Studio Mode

Use this mode for All Sorted Content Studio runs. It is brief driven and requires only the run's `brief.md` and `brand/BRAND-BRAIN.md` (or `brand.json`). Do not ask interview questions, read personal HookLab files, run market-research scripts, or browse research accounts.

Read the full brief and brand voice. Generate 10 distinct ad hooks using HookLab's established hook formulas: curiosity gap, specific situation, useful outcome, contrast, objection reversal, mistake or myth, short list, question, proof-led opener, and CTA bridge. Use only claims supported by the brief and approved brand evidence. Avoid sensitive personal-attribute targeting and unsupported promises.

Score each hook 0 to 10 for concreteness, mechanism strength, voice fidelity, audience relevance without personal-attribute targeting, and thumb-stop clarity. Show each axis and total out of 50. These are editorial scores, not performance predictions. Check every opener against `stale-openers.txt`; revise close matches. Return all 10 in rank order, with a one-line rationale and any evidence caveat. Save the result to `RUN_DIR/copy/hooks.md`.
